## REMOVED Requirements

### Requirement: Undo automatic moves
**Reason**: The action line offers a direct fix for every automatic move: Remove for an auto-queued or play-next episode, and Add to Queue or Play for a skipped or expired one. The Undo button added a second tap target to the row for the same result.
**Migration**: An automatic move still shows its reason in the row's status line ("Auto-queued", "Removed after 7 days"). The listener uses the action line to move the episode.
